Connect a free Supabase database so your library follows you across browsers and devices — not just this one. See the setup guide below the form for how to create one (takes about 5 minutes, no credit card).

Setup guide (~5 min, free)
  1. Go to supabase.com → sign up free → New Project (any name/password/region, no card needed).
  2. Once it's ready, open the SQL Editor and run: 
    create table library (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table library enable row level security;
create policy "anyone with the id can read/write"
  on library for all
  using (true) with check (true);
    This creates the table and turns on Row Level Security. The policy above allows access to anyone who has your Anon Key — that key is meant to be public in client apps like this one, so your real protection is the Library ID below: keep that one private, like a password.
  3. Go to Project Settings → API. Copy the Project URL and the anon public key into the fields above.
  4. Click Generate next to Library ID (or make up your own long string), then Connect below.
  5. On any other device/browser, install this same file and enter the exact same three values to see the same library.
